# 网卡智能关机助手

一个轻量的 Windows 自动关机工具，可根据 **倒计时、指定时间、实时总网速或指定 GPU 低负载条件** 自动触发系统关机。

当前版本：**V1.6**

## 功能

- 倒计时关机
- 指定日期时间关机
- 全部活动网卡合计速度持续低于阈值后关机
- 全部活动网卡合计速度持续高于阈值后关机
- 自动读取本机显卡数量与显卡名称
- 实时监控每张显卡的 GPU 使用率
- 实时监控每张显卡的专用显存占用与显存使用率
- 可指定某一张显卡作为关机判断对象
- GPU 使用率 **或** 显存使用率低于对应阈值时开始延迟计时
- GPU 条件中任意一项重新不满足后，延迟计时自动清零
- GPU 性能数据失效时暂停条件计时，避免误关机
- 自动保存上次设置
- 停止任务时可自动撤销 Windows 已排定的关机
- 本地日志记录

## GPU 低负载关机

1. 启动程序后，在“GPU 监控”区域确认检测到的显卡数量与实时数据。
2. 在“执行模式”选择：
   - `指定显卡：GPU使用率 或 显存使用率低于阈值`
3. 在“指定显卡”中选择需要监控的 GPU。
4. 分别设置：
   - GPU 使用率阈值，例如 `10%`
   - 显存使用率阈值，例如 `10%`
   - 关机延迟，例如 `60` 秒
5. 点击“启动任务”。

判断逻辑为 **OR**：

- GPU 使用率低于设定值；**或**
- 显存使用率低于设定值

任意一个条件满足就开始延迟计时。只有条件连续保持到设定秒数才会执行关机；期间如果两项都重新回到阈值以上，计时立即清零。

> GPU 模式下，“关机延迟”表示 GPU 低负载条件需要连续满足多少秒。达到该时间后立即执行关机命令，不再叠加第二段 Windows 倒计时。

## GPU 数据来源

- 使用 Windows DXGI 枚举图形适配器并读取显卡名称、LUID 与专用显存总量。
- 使用 Windows PDH Performance Counter 读取 `GPU Engine` 使用率和 `GPU Adapter Memory` 专用显存占用。
- 不依赖 NVIDIA-SMI，不需要单独安装第三方 GPU 监控程序。

某些老旧显卡驱动、远程桌面环境、虚拟显卡或损坏的 Windows 性能计数器可能无法提供完整 GPU 数据。程序会显示 `N/A` 或错误信息，并暂停对应 GPU 条件计时。

## 网速条件关机

1. 启动程序，等待实时网速初始化完成。
2. 选择：
   - 全部网卡合计低于阈值
   - 全部网卡合计高于阈值
3. 设置阈值、单位和需要持续满足的秒数。
4. 设置触发后的 Windows 关机延迟。
5. 点击“启动任务”。

## 时间输入格式

倒计时支持：

- `01:30:00`
- `90m`
- `2h`
- `3600s`

指定时间支持：

- `2026-08-17 23:30:00`
- `2026-08-17 23:30`
- `23:30:00`
- `23:30`

如果只输入时间且当天时间已经过去，程序会自动按第二天处理。

## 配置与日志

程序会在 EXE 所在目录生成：

- `settings.json`：保存上次设置
- `网卡智能关机助手.log`：运行日志

## 安全机制

- 网速条件任务必须等待网速初始化完成。
- GPU 条件任务必须获得指定 GPU 的有效数据。
- GPU/网速采样失效时会暂停条件计时。
- 条件不再满足时，持续计时自动清零。
- 触发关机后仍可使用“停止并取消”尝试执行 `shutdown /a` 撤销系统关机。
- 退出程序时，如果监控任务仍在运行，会再次提示确认。

第一次测试 GPU 模式时，建议把“关机延迟”设置为 60～120 秒，先观察状态栏是否按预期开始/清零计时。

## 构建源码

环境：Go 1.23 或兼容版本。

Windows x64：

```powershell
$env:GOOS="windows"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -trimpath -ldflags="-s -w -H=windowsgui" -o 网卡智能关机助手_V1.6.exe .
```

也可以直接使用仓库自带的 GitHub Actions 自动构建。

## V1.6 更新内容

- 新增 DXGI 多显卡枚举。
- 新增每张 GPU 实时使用率显示。
- 新增每张 GPU 专用显存使用量与显存使用率显示。
- 新增指定 GPU 低负载关机模式。
- GPU 条件由“GPU 使用率 **或** 显存使用率低于阈值”触发。
- 新增 GPU 条件连续延迟计时，条件恢复后自动清零。
- GPU 数据异常或超时会暂停条件计时，降低误关机风险。
- 保留 V1.5 的网速初始化修复、倒计时、定时及网速条件关机能力。

## 系统要求

- Windows 10 / Windows 11
- x64
- 支持 WDDM / DXGI 的图形驱动

程序通过 Windows 原生 `shutdown.exe` 执行关机和撤销关机操作。
